# Runnable examples

The `s_pneumoniae` example is a deliberately small, checked-in demonstration
of the generic utilities. It contains five phenotype/result pairs, a built 1313
library JSON, and five targeted control results. It is not a release-validation
dataset and must not be used for accuracy claims.

Run the commands in the parent `README.md` from the `amr-libraries` repository
root, replacing
the example paths with `evaluation-utils/examples/s_pneumoniae/...`. Generated
reports should be written outside this directory, for example under `/tmp`.
